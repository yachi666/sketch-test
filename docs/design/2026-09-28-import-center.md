# 导入中心优化 · 2026-09-28

预览：<http://127.0.0.1:5173/import>

## 问题与修复

旧的“已导入”卡片保留了外框，但缺少内部摘要区域布局，图标、名称和元数据堆叠。新的独立样式将来源、接口数量、导入时间和状态组织成网格，并对长 URL 做省略与详情换行。导入表单和操作指引分区，保持平台已有的暖色、薄荷绿和方格纸视觉。

## 流程检查

1. **填写来源：正常。** URL 表单明确说明支持 OpenAPI JSON/YAML；无效地址在本地提示并聚焦输入框。浏览器验证了无效地址提示，清空后恢复初始状态。截图 [页面概览](evidence/2026-09-28/import-center/01-overview.jpg)。
2. **查看已导入版本：正常。** 实际记录显示来源、59 个接口、时间和已导入状态，长地址没有挤乱卡片。搜索无匹配有独立提示，清空搜索恢复记录。截图 [已导入版本](evidence/2026-09-28/import-center/02-records.jpg)。
3. **展开版本详情：正常。** Enter 可展开原生详情控件，完整来源、版本 ID、内容指纹与诊断数量可查看；保留可见焦点。已导入只表示版本保存，不代表测试通过。
4. **导入与刷新失败恢复：单元测试通过。** 导入失败和历史读取失败分别提示；成功导入后若刷新失败，仍保留成功结果与原有记录。加载中、空记录和读取失败区分展示。
