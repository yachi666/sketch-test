# Agent 后端与正式 Web 验收（2026-10-10）

正式产品入口：http://localhost:8180/settings/agents 。原 4318 是独立设计原型；本轮已将浏览器切换到接入后端的正式产品。

## 已实现

- PostgreSQL 迁移 005：工作区连接、Agent、不可变版本、执行事件、原始草稿/计划。迁移重复运行安全，部署前已做本地数据库备份。
- 真实 API：Agent 创建/编辑/历史版本、连接登记与 Worker 在线检测、用例执行详情、用例来源。
- Agent 冻结快照包含 ID、版本、职责、厂商、模型、连接引用、超时、重试预算和输出限制。乐观锁避免覆盖别人的编辑；模型、连接或协议不匹配的 Worker 无法领取。
- 用例生成与计划建议都显式选择 Agent。修改或停用 Agent 不回写排队任务和历史记录。草稿审核修改不覆盖原始生成输出。
- 正式 Web 采用所选像素机器人视觉，包含三个真实持久化 Agent；用例详情可打开执行抽屉，计划建议内可展开执行来源。
- Worker 支持官方 Pi 的 OpenAI、DeepSeek、Anthropic、GLM 国际与中国 Coding provider。模型 ID 必须来自已安装 SDK 的对应目录。

## 当前边界

- 连接登记的是 Worker 引用。密钥仍在独立 Worker 环境，由部署配置提供；Web/Control Plane 不接收模型密钥。多个厂商/模型需部署各自的 Worker。
- OpenAI/GLM 没有可用真实凭据，本轮仅完成 provider 单元验证与多厂商调度集成测试，未声称完成其真实调用。
- 在线检测验证心跳与模型声明，不能代替真实模型请求；凭据有效性由真实生成验证。
- 状态通过轮询更新，模型/工具明细在成功提交结果时入库；失败任务保留失败码，不保证已有部分工具事件。未存储内部推理、原始 prompt 或原始厂商错误。
- 历史任务缺失的 Agent/原始输出数据明确标记为未记录，不伪造回填。
